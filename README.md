# govnoboy-cinnamon
Десклет для Cinnamon с картинками из тг-бота @govnoboybot
<img width="1919" height="1079" alt="изображение" src="https://github.com/user-attachments/assets/dc4fbd29-55b3-4f32-a1c3-96e346f53877" />
## Установка
Это мясо качается очень просто. Просто скачайте архив из releases и распакуйте в: ~/.local/share/cinnamon/desklets
Дальше просто включите его в настройках системы
## Требования
Cinnamon 6.0, 6.2, 6.4, 6.6, 6.8
## Функционал
Ну картиночки листать... показывает 10 картинок, раз в минуту обновляется... Ну или по нажатию кнопки, на ваш вкус... Картиночки можно скачивать
## Настройки
Размер
